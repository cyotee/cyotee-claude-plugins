# tevm

Progressive disclosure skills for Tevm - lightweight browser EVM for local testing, contract debugging, account management, and fork testing

## Skills

| Skill | Description |
|-------|-------------|
| `tevm-overview` | Lightweight EVM that runs in the browser. Use for local blockchain testing, contract debugging, and fork testing. |
| `tevm-setup` | Initialize Tevm clients for in-memory or fork mode. Use when setting up Tevm for testing or local development. |
| `tevm-actions` | Core Tevm actions for contract calls, mining, and state manipulation. Use when executing EVM operations with Tevm. |
| `tevm-account-management` | Get and set account state including balances, nonces, and storage. Use when manipulating EVM state for testing. |
| `tevm-contract-deployment` | Deploy contracts using ethers ContractFactory with Tevm. Use when deploying contracts in tests or local development. |
| `tevm-debugging` | Debug transactions with EVM tracing, gas profiling, and error handling. Use when investigating contract behavior or test |
| `tevm-events` | EVM step-by-step tracing for debugging contract execution. Use when debugging contracts or profiling gas usage. |
