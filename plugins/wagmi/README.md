# wagmi

Progressive disclosure skills for wagmi - React and vanilla JS Ethereum hooks for wallet connections, contract reads/writes, transports, and connectors

## Skills

| Skill | Description |
|-------|-------------|
| `wagmi-overview` | Vanilla JS Ethereum library built on viem. Use for wallet connections, contract interactions, and blockchain queries. |
| `wagmi-config` | Wagmi createConfig setup with chains and transports. Use when configuring multi-chain support and network connections. |
| `wagmi-connectors` | Wallet connectors for MetaMask, WalletConnect, injected, and more. Use when setting up wallet connections. |
| `wagmi-transports` | HTTP and WebSocket transports for blockchain connectivity. Use when configuring network connections. |
| `wagmi-read-contract` | Read contract data with type-safe ABI. Use when querying smart contract view/pure functions. |
| `wagmi-write-contract` | Write to contracts and send transactions. Use when executing state-changing contract functions. |
| `wagmi-react-overview` | React hooks library for Ethereum built on viem and TanStack Query. Use when building React apps with wallet connections  |
| `wagmi-react-providers` | WagmiProvider and QueryClientProvider setup for React. Use when configuring the React context for wallet and blockchain  |
| `wagmi-react-connect` | Wallet connection hooks for React. Use when connecting wallets and managing connection state. |
| `wagmi-react-hooks` | React hooks for blockchain queries and mutations. Use when reading/writing contracts or querying chain data. |
| `wagmi-react-read` | useReadContract hook for reading smart contract data. Use when querying contract view/pure functions in React. |
| `wagmi-react-write` | useWriteContract hook for sending transactions. Use when executing state-changing contract functions in React. |
