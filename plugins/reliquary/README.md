# reliquary

Progressive disclosure skills for Reliquary - maturity-based incentive system with ERC-721 Relic NFTs, level curves, and rolling rewarders

## Skills

| Skill | Description |
|-------|-------------|
| `reliquary-architecture` | This skill should be used when the user asks about "Reliquary", "maturity-based incentives", "Relic NFT", "level", "curv |
| `reliquary-deployment` | This skill should be used when the user asks to "deploy Reliquary", "add a Reliquary pool", "set up rolling rewarder", " |
